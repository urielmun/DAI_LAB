## 인공신경망 실습

데이콘 주최 대회 데이터를 활용한 인공신경망 분류 모델을 파이토치를 사용해서 구현해보았다. 

1. 데이터 전처리
- 수치형: 표준화
- 범주형(성별): 원 핫 인코딩
1. 신경망 구조 설계
- 입력층 노드 수: 11(수치+범주형 데이터)
- 출력층 노드수: 3(분류 문제이기 때문에 클래스 수)
- 은닉층의 수: 1 (대부분 1개면 충분하다는 의견)
- 은닉 노드의 개수: 실험적으로 결정 10,

느낀점

수치형 데이터를 표준화하고, 범주형 데이터를 원핫인코딩 하는 등의 전처리 과정이 있어야 AI의 학습이 가능하다. 

→ 올바른 데이터 전처리 과정을 적용해야한다. 

Sigmoid 함수를 활성화함수로 사용(은닉층, 출력층)한 것보다, LeakyReLU와 Softmax의 조합이 더 나은 성능을 가진다. 현대적인 딥러닝 방법론에는 ReLU 계열, 다중분류층에는 Softmax 방법을 적용하는 것이 표준이 된 이유를 보여준다. 

학습율에는 최적점이 존재한다. 학습율을 탐색하는 것은 다음 방법을 사용했다. 

**방법:** 로그 스케일로 몇 개의 학습률 후보를 정한 뒤(`[0.1, 0.05, 0.01, 0.005, 0.001]` 등), 각 후보로 모델을 잠시 (몇 에포크 정도) 훈련시켜 검증 데이터의 성능(F1 점수 또는 손실 값)을 비교합니다.

학습율이나 은닉층의 노드수의 세부튜닝을 진행할 수 있고, 은닉층의 수를 더 늘려 실험을 진행해볼 필요가 있다. 실험을 무계획적으로 진행하며 정확도를 높이는 것에 집중해서, 변수와 사용된 활성화함수를 비교하는데 부족함이 있었다. 다음에 진행할 때는 체계적인 계획을 기반으로 진행해야겠다.
